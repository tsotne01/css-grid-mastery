CSS Grid Quick Reference

Container Properties

display: grid; Creates a grid container
grid-template-columns Define column sizes
grid-template-rows Define row sizes
gap Space between items
grid-template-areas Name grid regions

Item Placement

grid-column: 1 / 3; Span columns 1-2
grid-row: span 2; Span 2 rows
grid-area: header; Place in named area

Alignment

justify-items Horizontal in cell
align-items Vertical in cell
place-items: center; Center both axes

Responsive Magic

repeat(auto-fit, minmax(200px, 1fr)) Auto-responsive columns
1fr Fraction of free space
minmax(min, max) Size range
